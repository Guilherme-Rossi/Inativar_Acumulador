# Estrutura recomendada para publicação no GitHub

Esta pasta reúne a estrutura mínima sugerida para o projeto ficar pronto para compartilhamento público.

## Diretórios principais

- docs/: documentação adicional e notas de publicação.
- imagens_rpa/: imagens usadas para reconhecimento visual.
- Relatorio Final/: saída de logs, screenshots e CSV consolidado.
- Relatório Inativação/: logs detalhados por empresa.

## Arquivos de entrada

Os arquivos abaixo devem ser colocados na raiz do projeto antes da execução:
- EMPRESA PARA INATIVAR ACUMULADOR.xlsx
- RELAÇÃO DE ACUMULADORES.xlsx

## Observação

A estrutura foi organizada para evitar depender de caminhos pessoais ou de máquinas específicas.
